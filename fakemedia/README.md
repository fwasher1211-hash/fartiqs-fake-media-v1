# Fake Media (client-side Fabric mod, MC 1.21.11)

- `/fakemedia` (or `/fakemedia on`) puts the media rank icon on the far left of your nametag, left of the + rank.
- `/fakemedia off` turns it off.

Client-side only: only you see it. Build: push to GitHub, open the Actions tab, download the `fakemedia-mod` artifact.
